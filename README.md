# Irys Solana Uploader - Educational Example

This repository is a simplified educational hands-on guide for learning how to use **Irys** (formerly Bundlr) to upload files permanently and in a decentralized manner to Arweave using a **Solana (SOL) wallet** on **Devnet** or **Mainnet**.

The goal is to demonstrate how to connect a wallet, query balances, fund the Irys uploader node, upload an image, generate a standard metadata (`metadata.json`) file, and upload that JSON. This workflow forms the foundation for creating decentralized NFTs on Solana.

---

## 📚 What is Irys?

**Irys** is a decentralized data provenance scaling network. It allows uploading data to **Arweave** (permanent storage where you pay once and data lasts forever) quickly, reliably, and with support for paying fees using tokens from other popular chains like Solana (SOL), Ethereum (ETH), Polygon (MATIC), etc.

### Key Concepts
1. **Permanence**: Files uploaded to Arweave via Irys are stored for life.
2. **Node / Uploader**: Irys maintains nodes where you upload your files. To perform uploads, you must transfer funds (in this case, SOL) from your Solana wallet to the Irys node (a process called *Funding*).
3. **Atomic Conversion**: Amounts are handled in the minimum unit of the token (in Solana, *lamports*, where 1 SOL = $10^9$ lamports). The SDK provides conversion tools (`utils.toAtomic` and `utils.fromAtomic`).

## 🛠️ Prerequisites

- **Node.js** (version 16 or higher).
- **TypeScript** installed globally or via project dependencies.
- A **Solana Wallet** with a SOL balance (either Devnet SOL for testing or Mainnet SOL for production).

---

## 🚀 Initial Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   Copy the example environment file `.env.example` and rename it to `.env`:
   ```bash
   cp .env.example .env
   ```
   Open the `.env` file and enter your Solana private key. The format can be:
   - A Base58 string (e.g. exported from Phantom or Solflare).
   - A JSON Array of numbers (e.g. from the private key file generated by Solana CLI: `[122, 45, 99...]`).

   *Optional*: If you have custom RPC endpoints (e.g., Helius, QuickNode, or Alchemy), you can set them under `SOLANA_DEVNET_RPC` or `SOLANA_MAINNET_RPC`.

3. **Place the Test Image**:
   Ensure you have an image file at `files/image.jpg`. This repository includes an example image, but you can replace it with any image you prefer.

## 🖥️ Scripts and Usage

This project exposes several helpful commands mapped in `package.json` to facilitate interaction and learning:

### 1. Check Balances
Displays the current balance in your Solana wallet and the pre-funded balance available on the Irys node.
```bash
# For Devnet (default)
npm run balance

# For Mainnet
npm run balance mainnet
```

### 2. Upload Image and Generate Metadata (Main Process)
This script executes the entire workflow sequentially:
1. Initializes the Irys uploader for the specified network.
2. Checks the Irys balance. (If you are on Devnet and your balance is 0, it will attempt to auto-fund 0.002 SOL if your wallet has funds).
3. Uploads the local image `files/image.jpg`.
4. Retrieves the Irys/Arweave URL for the uploaded image.
5. Creates a `files/metadata.json` file with standard NFT metadata and injects the image URL.
6. Uploads the `metadata.json` file to Irys.
7. Generates a structured log in `upload-log.md` containing the final links.

```bash
# For Devnet
npm run start

# For Mainnet
npm run start mainnet
```

### 3. Withdraw Funds from Irys
If you deposited more SOL than necessary onto the Irys node and wish to return it to your Solana wallet, you can perform a withdrawal.
```bash
# Withdraw a specific amount (e.g. 0.005 SOL) on Devnet
npm run withdraw 0.005

# Withdraw ALL available balance on Devnet
npm run withdraw all

# Withdraw ALL available balance on Mainnet
npm run withdraw all mainnet
```

### 4. Sync Manual Transaction (submit-tx)
If you perform funding manually on the Solana blockchain and the transaction is not reflected in your Irys balance, you can register the transaction Signature directly using this script:
```bash
npm run submit-tx <SOLANA_TX_SIGNATURE> [devnet | mainnet]
```

## 📂 Repository Structure

- [index.ts](./index.ts): Main execution file handling initialization, image upload, metadata generation, and metadata upload.
- [check-balance.ts](./check-balance.ts): Utility script to check balances in the wallet and on the Irys node.
- [withdraw.ts](./withdraw.ts): Utility script to withdraw funds deposited on Irys back to the wallet.
- [submit-tx.ts](./submit-tx.ts): Utility to manually submit transaction signatures to the Irys node in case of sync delays.
- `files/`: Directory containing the test image `image.jpg` and where `metadata.json` will be saved locally.
